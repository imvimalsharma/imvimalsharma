## 🚀 Featured Projects

### 🧠 [Vhini — Coding Assistant LLM From Scratch](https://github.com/imvimalsharma/Vhini)

A **7.3M-parameter LLaMA-style decoder-only Transformer** built and trained from scratch.

- Custom BPE tokenizer
- RMSNorm, RoPE & SwiGLU
- PyTorch training on Apple Silicon MPS
- 100M-token training run
- ONNX export & INT8 quantization
- Browser inference with ONNX Runtime Web
- Streaming coding assistant

> **Tokenizer → Transformer → Training → Quantization → Browser Deployment**

### 🤖 [Agentic AI](https://github.com/imvimalsharma/Agentic_AI)

Experiments and implementations around **agentic AI**, including agents, tools, orchestration and LLM-powered workflows.
